# TSSPrintMaster 1.0.3

Segundo ajuste del formato visual de las etiquetas.

## Cambios

- El tamaño de los textos aumenta de 20 a 22 puntos.
- La altura del código de barras se reduce de 69 a 62 puntos.
- El código de barras se desplaza a `Y=84` para conservar separación respecto al texto.
- Los ajustes se aplican tanto a Zebra/ZPL como a TSPL nativo.
