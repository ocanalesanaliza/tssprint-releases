# TSSPrintMaster 1.0.2

Actualización del formato de las etiquetas impresas.

## Cambios

- Se aumentó ligeramente el tamaño de los textos de área, paciente y edad/género.
- Se redujo un 20% la altura del código de barras.
- Se ajustó la posición vertical del código de barras para evitar que se superponga con el texto más grande.
- Los cambios se aplican tanto a impresoras Zebra/ZPL como a impresoras con TSPL nativo.

Los equipos instalados recibirán esta versión mediante la tarea automática `TSSPrintMaster-Actualizacion`.
