# TSSPrintMaster 1.0.5

Nuevo ajuste visual del formato de etiquetas.

## Cambios

- El nombre del paciente aumenta de 22 a 26 puntos.
- La altura del código de barras se reduce un 20%, de 62 a 50 puntos redondeados.
- Se redistribuyen verticalmente la edad y el código de barras para evitar superposiciones.
- Los cambios se aplican tanto a Zebra/ZPL como a TSPL nativo.
- Se conserva el desinstalador integrado incorporado en `v1.0.4`.
